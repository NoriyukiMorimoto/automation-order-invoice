# 開いたままVBA更新

`自動化_注文書_請求書.xlsm` を開いたまま、`運用中VBA` のコードをブックへ反映します。

## 使用方法

1. Excelで `自動化_注文書_請求書.xlsm` を開く。
2. セルの編集中やダイアログ表示中でない状態にする。
3. `開いたままVBA更新.cmd` を実行する。

更新後もブックとExcelは開いたままです。

## 更新対象

- 標準モジュール
- `ThisWorkbook`
- `Sheet1`
- ユーザーフォームのコード

フォームのレイアウトと `.frx`、ワークシート、セル内容は変更しません。

## 前提

Excelの「VBAプロジェクト オブジェクト モデルへのアクセスを信頼する」が有効である必要があります。

Excelを管理者として起動した場合は、このコマンドも同じ権限で実行してください。実行権限が異なると、開いているExcelへ接続できません。
