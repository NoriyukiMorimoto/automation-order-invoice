# 設計プラン: 施工会社確定時の注文書テンプレート取込・内訳明細転記

対象ブック: `自動化_注文書_請求書.xlsm`
作成日: 2026-07-08 / ステータス: 実装済み（mod_OrderTpl_Shared / Generate / Header / Detail、Sheet1.cls フック追加。詳細は CHANGELOG.md 参照）

---

## 1. 概要

基本情報シートの施工会社（11行目: F11, I11, … 3列おき・最大10社）が確定されたら、
`マスタデータ/注文書テンプレート.xlsx` の全5シート（内訳明細・受注者用・注文請書・支店控・別紙Ⅲ）を
購入充当指示（または購入充当通知）シートの右側に会社ごとに挿入し、シート名末尾に業者マスタP列の略称を付帯する。
内訳明細シートにはヘッダー情報＋施工指示書（工事/溶接）の明細データを転記する。

確認済みの方針:

- 同一会社ブロックの再入力時は既存5シートを **削除して再作成**
- 施工指示書（工事/溶接）が未取込の場合は **ヘッダーのみ転記し、後から再転記マクロで明細を反映**
- 施工指示書か施工通知書かは **ブック内に存在する方を自動使用**（mod_common の名称関数で解決）

---

## 2. トリガーと呼び出し経路

既存の `Sheet1.cls` の `Worksheet_Change` は 11行目（F11, I11, …）を監視済みで、
`mod_VendorMaster.FillVendorInfoToBasicInfo` が会社情報を展開している。

- この直後に新規公開APIを1行フックする:
  `mod_OrderTpl_Generate.GenerateVendorOrderSheets vendorIndex`
- 11行目が **空にクリアされた** 場合は該当会社の5シートを削除する（`RemoveVendorOrderSheets vendorIndex`）。
- イベント制御は既存パターンを踏襲（`EnableEvents=False` / `ScreenUpdating=False` / `Calculation=Manual`、末尾で復元）。

## 4. 処理フロー

### 4.1 略称・業者名の解決（照合キー）

1. 基本情報 B6（支店名 例: 大阪支店）と一致する `業者マスタ(全社版).xlsx` のシートを開く（ReadOnly）。
2. 当該会社ブロック11行目の会社名と B2:B51（請求者氏名）を正規化比較（`CommonNormalizeText` 利用）。
3. 一致行から以下を取得:
   - **P列: 略称**（例 `(泉州)`）→ 5シートのシート名末尾に付帯（例 `内訳明細(泉州)`）
   - **A列: 業者名**（例 `泉州軌道整備㈱`）→ 施工指示書A列/溶接シートB列との明細抽出キー
   - **O列: 担当工事** → 転記パターンの参考情報（判定の主キーは基本情報10行目の工事区分）
4. 一致なし → 警告メッセージを出しシート挿入を中止（ログ記録）。

### 4.2 シート挿入・再作成

1. 既に同略称の5シートが存在する場合は削除（`DisplayAlerts=False`）。
2. `注文書テンプレート.xlsx` を ReadOnly で開き、`Sheets(Array("内訳明細","受注者用","注文請書","支店控","別紙Ⅲ")).Copy After:=アンカー` で一括コピー→リネーム→テンプレートを閉じる。
3. アンカー決定ロジック:
   - 1社目: `購入充当指示` / `購入充当通知` シート（`CommonPurchaseOrderOutputSheetName` / `CommonPurchaseNoticeOutputSheetName` で存在する方）の直後
   - N社目: (N-1)社目の `別紙Ⅲ(略称)` の直後（略称は各ブロックを4.1で都度解決）
   - 途中の会社が未確定でも、確定済み会社の並び順（ブロック順）を保って右に追加
4. 内訳明細（略称）シートに印刷タイトル行 `$7:$10` を設定（複数ページ対応）。

### 4.3 内訳明細ヘッダー転記（会社ブロック列 = F+3×(n-1) 列）

| 転記先 | 内容 | 備考 |
|---|---|---|
| C2 | 部店コード | `出張所別_単価適用線区.xlsx`/単価適用線区: B列=基本情報B6 かつ C列=基本情報C6 の行の G列 |
| C3 | 注文番号 | 会社ブロック27行目（F27, I27, …） |
| B6 | 工事番号 | 基本情報 C9 |
| C6 | 工事件名 | 基本情報 C10（C6:G6結合、左右上下中央揃え） |
| K5 / K6 | 工期 自/至 | 基本情報 C15 / C16（結合、中央揃え） |
| N2 | 作成日 | 基本情報 C2（結合、中央揃え） |
| N3 | 所長名 | 基本情報 F6（結合、中央揃え） |
| O5 | 外注会社名 | 会社ブロック11行目（結合、中央揃え） |
| O6 | 業者コード | 会社ブロック16行目（結合、中央揃え） |

入力セルはすべてフォント **BIZ UDゴシック**（明細部含む。共通ヘルパーで一括適用）。

### 4.4 明細転記（11行目〜小計行の直前）

**共通ルール**

- テンプレート初期状態は 11〜32行がデータ域、A33=小計。データが小計行の1行上に達したら小計行直前に行挿入し、小計以下を下へずらす（挿入行にも G/N〜P の数式・書式を引き継ぐ）。
- セクション構造: 見出し行（契約線区名_管理室 等）→ データ行群 → 空白1行 → 次セクション。
- セクション内ソート: 第1=昼夜別（昼が上）、第2=整理番号 昇順（`mod_common` の配列ソート利用）。
- 列マッピング（データ行）:
  - A: 整理番号（左右中央揃え）
  - B: 工事種類（左詰め・縮小して全体を表示）
  - C: 昼夜別（左右中央揃え）
  - D: 単位
  - E: 数量 … 単位が {口, 穴, 回, 個, 箇所, 本, 組, 式, 枚} → 整数（表示形式 `0`）／ {m, m3, M, m², t} → 小数3桁（`0.000`）
  - F: JR単価 … 整数（小数点なし）
  - G: 数式 `=E{r}*F{r}`（表示形式 General: 小数が出れば全桁表示、出なければ整数表示）
  - N / O / P: E / F / G と同内容（Pは `=N{r}*O{r}` 数式）
- 抽出元シート名は指示書/通知書の存在する方を自動選択。両方無い場合はヘッダーのみで終了（メッセージ＋ログ）。

**パターンA: 工事区分（10行目）= 軌道工事**

1. 施工指示書(工事)/施工通知書(工事): A列施工業者 = 業者名（4.1で解決）で抽出。
   - セクションキー: G列契約線区名（末尾の `(軌道)` を除去）＋ `_` ＋ H列管理室
   - 転記元列: B整理番号 / C工事種類 / D昼夜別 / E単位 / F数量 / I JR単価
2. 工事分の最終行から **2行空けて**、施工指示書(溶接)/施工通知書(溶接): B列軌道手元会社 = 業者名で抽出。
   - セクションキー: H列契約線区名（`(溶接指示書用)` を除去）＋ `_レール溶接_` ＋ I列管理室
   - 転記元列: C整理番号 / D工事種類 / E昼夜別 / F単位 / G数量（桁切りなし）/ J JR単価

**パターンB: 工事区分（10行目）= 溶接工事**

- 工事シートからの取込なし。施工指示書(溶接)/施工通知書(溶接): **A列溶接会社** = 業者名で抽出。
- セクションキー・列マッピングはパターンAの溶接分と同一。

### 4.5 再転記エントリポイント

- 公開Sub `RefreshVendorOrderDetails(Optional vendorIndex)` を用意（引数省略時は全確定会社）。
  既存内訳明細（略称）の明細部（11行目〜小計直前）をクリアし、余剰挿入行を削除して標準行数へ戻した上で再構築。
- 施工指示書等の取込完了後にユーザーが実行できるようボタン（またはリボン/図形マクロ登録）を配置。
  ※既存の取込処理（`mod_Construction_Import_Load`）完了時の自動呼び出しは影響範囲が広いため第2段階とする。

## 5. 懸念点・実装時の確認事項

1. **シート名の表記ゆれ**: 現ブックの実シートは「施**行**指示書(工事)」だが、`mod_common` の名称関数は「施**工**指示書(工事)」を生成する。抽出元シートの解決は名称関数＋正規化比較（施行/施工の両表記許容）でフォールバックする。
2. **略称の重複**: 同一会社を複数ブロックに入力した場合、シート名が衝突する。検出時は警告して2社目以降の挿入を中止（運用上想定外のため）。
3. **数量の型**: 溶接明細の数量は「桁切りなし」指定のため表示形式 General で数値のまま転記。
4. **受注者用・注文請書・支店控・別紙Ⅲ** への転記仕様は今回未指定のため、コピー＋リネームのみ（転記仕様は別途指示を受けて追加）。
5. **性能**: 明細は配列に組み立ててから一括代入。書式（中央揃え/縮小表示/表示形式/フォント）は列単位・範囲単位でまとめて適用。
