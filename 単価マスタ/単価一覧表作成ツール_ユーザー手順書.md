# 単価一覧表作成ツール ユーザー手順書

## 1. このツールでできること

このツールは、参照元フォルダ内の単価一覧Excelを読み取り、保線区・年度・通常単価/設計変更単価・工事件名ごとにExcelファイルを作成します。

PowerShell版はEDRで検知されるため使用しません。現在はExcel VBA版を使用します。

## 2. 推奨フォルダ構成

`単価一覧表作成ツール.xlsm` は、`単価マスタ` フォルダ直下に保存してください。

```text
単価マスタ
├─ 単価一覧表作成ツール.xlsm
├─ UnitPriceListTool.bas
├─ 出張所別_単価適用線区.xlsx
├─ 工事件名別マスタ
├─ 近畿統括本部
├─ 金沢支社
└─ logs
```

`単価一覧表作成ツール.xlsm` と `出張所別_単価適用線区.xlsx` が同じフォルダにある場合、ツールはそのフォルダを自動で `単価マスタ` フォルダとして判定します。

## 3. 初回準備

通常利用時は、すでにマクロと実行ボタンを設定済みの `単価一覧表作成ツール.xlsm` を使用してください。

初回作成または修正時のみ、次の作業を行います。

1. Excelで `単価一覧表作成ツール.xlsm` を開きます。
2. `Alt + F11` を押してVBA画面を開きます。
3. VBA画面で `ファイル` → `ファイルのインポート` を選びます。
4. `UnitPriceListTool.bas` を選択してインポートします。
5. Excelに戻り、シート上のボタンに `CreateUnitPriceLists` マクロを割り当てます。
6. ボタン名を `単価一覧表作成実行` にします。
7. マクロブック `単価一覧表作成ツール.xlsm` を上書き保存します。

すでに文字化けしたモジュールを取り込んでいる場合は、VBA画面で該当モジュールを削除してから、もう一度 `UnitPriceListTool.bas` をインポートしてください。

## 4. 実行手順

1. `単価一覧表作成ツール.xlsm` を開きます。
2. マクロが無効になっている場合は、Excel上部の警告からマクロを有効化します。
3. シート上の `単価一覧表作成実行` ボタンをクリックします。
4. 最初に参照フォルダ選択画面が表示されます。
5. 次の参照元フォルダ、またはその配下の `近畿統括本部` / `金沢支社` フォルダを選択します。設計変更単価のように、直下に `0202北陸広域鉄道部` や `0501福知山保線区` などの保線区フォルダが並んでいるフォルダも選択できます。

```text
\\dt-ims\公開フォルダ\090_線路本部\008_単価契約関係
```

6. 選択フォルダ内に `近畿統括本部` と `金沢支社` の両方がある場合は、両方をまとめて処理します。どちらかの本部・支社フォルダを直接選択した場合は、そのフォルダだけ処理します。保線区フォルダが直下に並んでいる場合は、同じフォルダを参照して `近畿統括本部` と `金沢支社` の両方を処理します。
7. 処理が完了すると、完了メッセージとログファイルの場所が表示されます。

マクロ入りExcelがSharePoint/OneDrive上のURLとして開かれている場合でも、同期済みのローカルフォルダから `単価マスタ` フォルダを自動検出します。`単価マスタフォルダを選択してください` という2回目のフォルダ選択は表示されません。

自動検出できない場合は、SharePointの同期状態、または `単価一覧表作成ツール.xlsm` が `単価マスタ` フォルダ配下に保存されているかを確認してください。

## 5. 処理の流れ

ツールは次の順番で処理します。

1. `出張所別_単価適用線区.xlsx` を開きます。
2. `単価適用工事件名マスタ` シートの `A2:A10` から工事件名を取得します。
3. 工事件名の先頭文字から工事件名コードを取得します。

```text
① → 1
④ → 4
⑫ → 12
```

4. `工事件名別マスタ\工事件名.xlsx` を開きます。
5. 選択した本部・支社名と同じシートを読みます。
6. C列の保線区コード、D列の積算線区コード、F列の積算線区名を取得します。
7. 次の番号で参照元の単価一覧Excelを探します。

```text
工事件名コード + 保線区コード + 積算線区コード
```

例:

```text
①軌道整備他 + 0501 + 01
→ 1 + 0501 + 01
→ 1050101
```

8. `(ｼｽﾃﾑ)` または `システム` を含むファイルは対象外にします。
9. 単価一覧Excelの1枚目のシートをコピーします。
10. コピーしたシート名は、元ファイルの `B4` の値にします。

`出張所別_単価適用線区.xlsx` と `工事件名別マスタ\〇〇.xlsx` は読み取り専用で開き、保存せずに閉じます。列幅、フォント、セルの値などの書式は変更しません。

## 6. 出力先とファイル名

出力先は、`単価マスタ` フォルダ配下の `近畿統括本部` または `金沢支社` フォルダです。

通常単価の場合:

```text
単価マスタ\近畿統括本部\0501福知山保線区\2026\通常単価
```

設計変更単価の場合:

```text
単価マスタ\近畿統括本部\0501福知山保線区\2026\設計変更単価
```

`2026` フォルダや `通常単価` / `設計変更単価` フォルダが無い場合は、自動で作成されます。

出力ファイル名の例:

```text
通常_2026_0501福知山保線区_①軌道整備他.xlsx
設計変更_2026_0501福知山保線区_①軌道整備他.xlsx
```

工事件名ごとに別々のExcelファイルが作成されます。

## 7. 出力Excelのシート構成

出力Excelには、積算線区ごとにシートが作成されます。

例:

```text
通常_2026_0501福知山保線区_①軌道整備他.xlsx
├─ 1050101側ExcelのB4の値
├─ 1050102側ExcelのB4の値
└─ 1050103側ExcelのB4の値
```

参照元の単価一覧Excelは必ず1シートという前提のため、その1シートを出力Excelへコピーします。

保存前に、出力Excelの全シート・全セルのフォント名を `BIZ UDゴシック` に統一します。フォントサイズは変更しません。

## 8. 既存ファイルがある場合

同じ名前の出力ファイルがすでにある場合、その出力ファイルの作成処理はスキップします。

請求書マクロから単価ファイルを呼び出すため、出力ファイル名は常に同じ名前になります。

```text
通常_2026_0501福知山保線区_①軌道整備他.xlsx
```

既存ファイルを更新したい場合は、対象の出力ファイルを削除してから再実行してください。

スキップのリスク:

- 参照元の単価一覧Excelが更新されていても、既存の出力ファイルは更新されません。
- 一部のシートだけ追加・差し替えたい場合も、同名の出力ファイルがある限り処理されません。
- 古い出力ファイルが残っていると、請求書マクロは古い単価を参照します。
- 前回実行が途中でエラーになって作成されたファイルも、次回は既存ファイルとしてスキップされます。作り直したい場合は対象ファイルを削除してから再実行してください。

## 9. ログの確認

実行ログは `logs` フォルダに作成されます。

```text
単価マスタ\logs\unit-price-list-vba_yyyymmdd_hhnnss.log
```

ログには、読み込んだマスタ、スキップした工事件名、未検出フォルダ、保存したファイル名、エラー内容が記録されます。

## 10. よくあるメッセージ

### スキップ: 工事件名別マスタが見つかりません

`出張所別_単価適用線区.xlsx` の `A2:A10` に書かれている工事件名に対応するExcelが、`工事件名別マスタ` 直下にありません。

必要なければ問題ありません。その工事件名の出力ファイルは作成されません。

### 未検出: 保線区フォルダ

参照元フォルダ側に、対象の保線区フォルダが見つかりません。

保線区コードとフォルダ名を確認してください。

### 未検出: 保線区フォルダ内の工事件名

参照元フォルダ側の保線区フォルダ内に、対象の工事件名フォルダが見つかりません。

例:

```text
0501福知山保線区\①軌道整備他
```

### 作成対象ファイル数: 0

条件に合う単価一覧Excelが見つからなかった状態です。

次を確認してください。

- `出張所別_単価適用線区.xlsx` の `A2:A10`
- `工事件名別マスタ\〇〇.xlsx`
- 選択した `近畿統括本部` / `金沢支社`
- 参照元フォルダ内の保線区フォルダ
- 単価一覧Excelのファイル名
- `(ｼｽﾃﾑ)` / `システム` ではない通常ファイルが存在するか

## 11. 注意事項

- `Start-UnitPriceListApp.cmd` は現在、実行用ではありません。
- PowerShell版はEDRで検知されるため使用しません。
- 実行はExcelシート上の `単価一覧表作成実行` ボタンから行います。
- ボタンが表示されない、または動かない場合は、ボタンに `CreateUnitPriceLists` マクロが割り当てられているか確認してください。
- 空の工事件名別マスタは、必要なければ `工事件名別マスタ\未使用` などの配下フォルダへ移動してください。
- `出張所別_単価適用線区.xlsx` の `A2:A10` に記載されていない工事件名は処理されません。
- 実行前に、作成先のExcelファイルを開いている場合は閉じてください。
